ПАКЕТ БАЗЫ LEGION WIKI

catalog.json — публичные сведения о предметах и встроенные иконки.
version.json — ревизия, SHA-256, путь каталога и число предметов.
index.html — страница с прямыми ссылками на файлы.
.nojekyll — публикация файлов без обработки Jekyll на GitHub Pages.
_headers — заголовки для альтернативного размещения на Cloudflare Pages.

Пакет подготовлен для бесплатного статического размещения.
Само наличие этих файлов не означает, что база уже опубликована.
В выпущенной версии 3.17.0 сетевых обновлений ещё нет.
Загрузчик и локальный кэш подготовлены в исходниках следующего выпуска.
После публикации: python tools/configure_update_feed.py HTTPS-адрес/version.json
Затем нужно собрать и один раз установить новые клиенты.

Пересборка: python tools/build_update_feed.py
Публиковать следует только содержимое этой папки, а не весь исходный проект.
